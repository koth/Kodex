# VRoid 复刻指导清单

照这份清单在 **VRoid Studio** 里捏出角色，导出 `.vrm`，即可被现有管线直接加载驱动。
参考图（同目录）：`ref/hero-v1.png`（正脸定妆）、`ref/turnaround-v1.png`（三视图）、`ref/expressions-v1.png`（表情）。
**目标：像，而不是美。** 捏每个部位时对照 `hero-v1.png`，别凭感觉自由发挥。

---

## 0. 开工前

- 用 VRoid Studio **正式版**（非手机版），新建**女性**模型。
- 体型：标准成年女性，身高默认即可（渲染层按包围盒自动取景，不挑身高）。
- 导出格式选 **VRM 0.x 或 1.0 都行**（`three-vrm` 两者都认）；保持默认导出设置即可。

---

## 1. 脸（Face）—— 最重要，先捏脸

对照 `hero-v1.png` 正面：

- **脸型**：圆润鹅蛋脸。把"脸部宽度 / 下颌"往**圆润、柔和**调，下颌线不要尖、不要棱角。
  - 下巴：偏短、偏圆（下巴长度↓、下巴尖↓）。
  - 脸颊：略饱满（脸颊饱满度略↑），营造乖巧感。
- **眼睛**（气质核心）：大而温润的**杏眼**。
  - 眼型：横向略长、纵向开合适中偏大；眼角不要上吊（避免媚/凶），保持**平或微微下垂**显温顺。
  - 眼睛位置：略低于中线一点，间距适中（别太近）。
  - 双眼皮：自然的内双/窄双，不要夸张欧式大双。
- **眉毛**：淡平眉。
  - 形状：平直、略细、浓度低；眉峰几乎无，眉尾不下掉。
  - 颜色：浅棕/灰棕（比头发浅）。
- **鼻子**：小巧、鼻梁不高，鼻头圆润——二次元化处理，弱化存在感。
- **嘴**：小嘴，自然粉唇，**嘴角微微上扬**的浅笑（静态默认表情就是温和浅笑）。
- **腮红**：淡粉，低浓度，打在颧骨偏下的位置（温柔感来源之一）。

---

## 2. 发型（Hair）—— 第二重要

对照 `hero-v1.png` / `turnaround-v1.png`：

- **整体**：黑色**长直发，及腰**（后背长度到腰）。
- **刘海**：**空气感齐刘海**——轻薄、略过眉、能看到一点额头/眉毛，不要厚重齐刘海，也不要斜分。
- **须发（サイド）**：两侧各一缕**长须发**，垂到胸前/锁骨下，框住脸。
- **发色**：纯黑或近黑的深黑（`#1a1a1e` 左右，避免明显棕/蓝高光）。
- **光泽**：低光泽、柔和，不要油亮。
- VRoid 实现建议：用"直发"发型组打底，前发选/画出轻薄空气刘海，两侧手动加长发束当须发，后发拉直拉到腰。

---

## 3. 配色（皮肤 / 瞳 / 整体色调）

- **肤色**：自然偏白的东亚肤色，暖调，低饱和。
- **瞳色**：深棕近黑（暖棕 `#4a2f28` 左右），可加一点柔和高光点；**不要**彩色/异色瞳。
- **整体色调**：低饱和、柔和、偏冷的灰蓝系（和开衫呼应），避免高饱和撞色。

---

## 4. 服装（Costume）

对照 `hero-v1.png` 上半身：

- **浅灰蓝针织开衫**：宽松款、柔软针织质感，长度到胯附近，**白色大圆扣**（2~3 颗，显眼）。
- **内搭**：天蓝色（浅 baby blue）高领/半高领贴身内搭。
- 下装/鞋：三视图里偏居家（及膝短裤 + 浅色袜/拖鞋），**模型以半身为主时从简**，但请保持柔和浅色系。
- 配色关键词：灰蓝 / 天蓝 / 白，低饱和柔和。
- VRoid 实现：内置衣柜里找"针织开衫 + 高领内搭"组合，改色到灰蓝/天蓝即可；扣子用贴图或选带大扣款。

---

## 5. 表情预设（Expressions）—— 管线硬性要求

`CompanionAvatar` 的 `MOOD_EXPRESSIONS` 直接驱动**标准 VRM 表情预设**，模型必须带齐：

- 必需：`happy` `sad` `angry` `surprised` `relaxed` `neutral`
- 必需：`blink`（眨眼）
- 建议：`aa` `ih` `ou` `ee` `oh`（口型，后续若加语音口型用得上）

VRoid 默认导出已带这套标准预设，**导出时不要删**。可在 VRoid 表情面板微调各预设强度，使其贴近 `expressions-v1.png` 里对应那一格（尤其 happy / pouty-angry / sleepy-relaxed）。

---

## 6. 导出前自检（对照管线要求）

- [ ] humanoid 骨骼完整（VRoid 默认就是，别手动删骨）。
- [ ] 含标准表情预设（见第 5 节）。
- [ ] 模型 ≤ 30MB、贴图 ≤ 2K（VRoid 导出时可选降贴图分辨率，选 2048 即可）。
- [ ] 材质为 **MToon**（VRoid 默认），不要用 Unlit/Standard 替换。
- [ ] 正面朝向：VRoid 导出默认面向 +Z，渲染层已 `rotation.y = π` 转向相机，无需改。

---

## 7. 导出后：本地验证 + 接入

把导出的 `.vrm` 放好后，两条验证路径：

**A. 用探查脚本验证骨骼**（仓库自带）：
```bash
node apps/desktop/ui/scripts/inspect-vrm.mjs /path/to/你的模型.vrm
```
应打印出 `humanBones` 列表（hips/spine/chest/head/leftUpperArm/...）。缺骨说明导出不完整。

**B. 接进 app**：
1. 设置 → 陪伴角色 → 「选择 VRM…」选中你的 `.vrm`（后台会复制到 `~/.kodex/companion/`）。
2. 工作台右下角应渲染出她，并随会话状态切换表情/姿态。
3. 重点看：idle 双手身前交叠是否自然、happy 是否微笑、注视跟随是否工作。

加载失败会自动回退到占位头像，并在悬浮层提示错误——把错误信息发我即可定位。

## 常见坑

- **脸崩/不像**：90% 是脸型和眼睛没对照定妆照。回去重捏第 1 节，眼睛形状是第一优先级。
- **刘海太厚**：空气刘海要"透"，能看到额头。发片别叠太多。
- **表情没反应**：多半是导出的预设名不是标准的 `happy/sad/...`。VRoid 默认是对的，改过就要改回标准名。
- **穿模（手臂进裙子/胸口）**：渲染层 idle 已做前臂解析 IK，一般稳；若严重穿模，把模型胸围/臂围调自然些。
