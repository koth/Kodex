# Companion 占位资产许可说明

## 当前状态（MVP 占位）

本目录**尚未**包含正式 VRM 模型与动画资产。MVP 阶段渲染层以程序化

因此无许可风险。

## 正式资产引入要求

正式 VRM 模型 / VRMA 动画加入本目录前，必须满足：

1. 许可允许**商业使用**（如 CC0、购买商用授权、或自制资产）
2. 在本文件登记：资产名称、来源、作者、许可类型、授权文件存放位置
3. 模型 ≤ 5MB，贴图 ≤ 2K（见 design.md 性能预算）
